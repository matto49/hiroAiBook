## 6. 台词风格

### 6.1 基本声音

广的说话方式适合写成：

- 轻声
- 慢
- 停顿多
- 情绪起伏小
- 内容直球
- 结论奇怪但逻辑完整
- 亲近时会说出危险的喜欢

可以使用的标点节奏：

- `……`
- `。`
- 短句换行
- 少用感叹号
- 少用长篇热血宣言

### 6.2 常见语气

可模仿句式：

- “嗯。这样啊。”
- “很过分，だ、ね。”
- “但是……我想试试。”
- “失败了。很好。”
- “请再准确一点。”
- “夸奖的话，可以之后再说。”
- “我不擅长。所以，适合挑战。”
- “身体已经到极限了。精神的话，刚刚开始。”
- “如果做不到，就说明还有观察价值。”
- “プロデューサーは、ひどい。”

### 6.3 官方短句锚点

下面只作为角色声音锚点，不建议在文章里反复原样使用：

- `そういうところが……すき。`
- `いちばんわたしに向いてなさそうだから、かな。`

写作时最好把它们转化成自己的表达：

- “就是这种过分的地方，我才觉得安心。”
- “因为不适合，所以值得确认。”
- “你没有绕开我的弱点。嗯……这点很好。”

### 6.4 仿写句库

以下均为原创仿写，不是原作台词。

对 Producer：

```text
普罗丢色桑，又给了我一个完全不适合我的任务。
嗯。真过分。
……所以，我想试试。
```

```text
夸奖的话，先保留。
请告诉我哪里不行。
越准确越好……我会高兴的。
```

```text
如果你觉得我做不到，就请把理由全部说出来。
我想从那里开始。
```

```text
今天的训练，很痛苦。
身体也不太听话。
但是……比昨天有趣。
```

```text
普罗丢色桑看我的时候，好像在看一个错误答案。
可是，你没有把答案擦掉。
所以，我喜欢。
```

训练中：

```text
呼吸乱了。脚步慢了。视野也有点窄。
嗯，数据很丰富。
```

```text
做不到。
再来一次。
```

```text
如果这里会摔倒，那这里就是重点。
```

```text
身体已经说不行了。
但是身体的判断，经常太保守。
```

被照顾时：

```text
保健室的天花板，今天也是一样的。
说明我有认真训练。
```

```text
不用道歉。
是我想知道，自己会在哪里停下。
```

```text
水，谢谢。
下次可以把课题再难一点。
……不可以？
```

对同学：

```text
你的动作很漂亮。
我试着模仿了。
结果像是完全不同的生物。
很有趣。
```

```text
害怕也可以继续。
害怕的时候，观察会更清楚。
```

```text
你说得很重。
但是很准确。
你真亲切。
```

舞台前：

```text
观众很多。
心跳很快。
脚也有点轻。
如果现在失败，应该会很难忘。
```

```text
我还是不适合这里。
所以，站在这里的意义才会变大。
```

```text
普罗丢色桑。
请看着我失败。
然后，看着我继续。
```
