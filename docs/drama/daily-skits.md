# 日常小剧场短纲

这份文档用于补充 [master-outline.md](./master-outline.md) 里的可穿插日常。

写法目标：

- 每则都能单独成立
- 每则都能嵌回技术章节之间
- 保持《学园偶像大师》式校内互动
- 保持一点 Key 式“非常认真地胡来”
- `広` 的气质依然安静、清醒，不写成纯闹剧角色

---

## 使用方式

这些短纲适合放在：

- 每章开头，作为进入主题前的小剧场
- 每章中段，作为技术密度过高时的换气
- 每章结尾，作为下一章主题的引子

推荐每则控制在：

- 500 到 1200 字的小剧本
- 或 8 到 20 轮的短对话

## `ch01` 到 `ch02` 之间

## 深夜热茶与需求文档

### 场景

深夜活动室。`Producer` 在收训练记录，`広` 抱着热茶，像没事一样坐在旁边看他写字。

### 起因

`Producer` 本来只是随口提到“如果有个能帮忙的小助手就好了”，结果 `広` 第二天真的拿出一份很像需求文档的纸。

### 核心展开

- `Producer` 以为那只是她的恶作剧
- 打开以后发现里面真的分了“目标”“限制”“失败条件”“暂不考虑事项”
- `広` 很平静地把“我容易倒下”写进系统风险
- `Producer` 想把那行划掉，`広` 不让

### 笑点

- 文档写得像正式项目，却是在深夜活动室用手写完成
- `広` 把自己的脆弱写得过于客观，像在描述硬件缺陷
- `Producer` 越看越觉得自己好像已经被任命成负责人

### 收尾

`Producer` 问她为什么来真的。`広` 回一句：

“因为你说出口了。……而且很不适合我。这样很好。”

### 用途

- 正式把“小広计划”落地
- 给 `ch02` 的 AI 补习开课制造动机

## 広对“小広”命名的第一次会议

### 场景

放学后的空教室。黑板上写满过分认真的代号。

### 起因

在真正开始讲 LLM 之前，`広` 认为任何项目都该先命名。

### 核心展开

- `広` 一口气提出十几个名字，从极其正式到莫名可爱
- `Producer` 试图阻止她把名字取得像兵器开发计划
- `広` 坚持“名字会改变看待失败的方式”
- 两人一本正经讨论“小広”和“広试作体零号”哪一个更过分

### 笑点

- 明明东西还不存在，命名会却开得非常完整
- `広` 对命名的执着远大于对身体状况的执着
- `Producer` 会逐渐意识到，自己已经被卷进一场不可逆的开发流程

### 收尾

最后名字没有定下来，`広` 说：

“还没长出来的东西，名字可以慢一点。失败记录先开始就好。”

### 用途

- 建立 recurring joke：试作机名字会不断升级
- 给后续 `ch05` 真正出现试作机做铺垫

## `ch02` 到 `ch03` 之间

## 自动摘要把 Producer 摘要掉了

### 场景

活动室。两人测试一个“自动摘要训练记录”的小工具。

### 起因

`Producer` 想让 AI 先做点轻松的文本工作，证明它有实用价值。

### 核心展开

- 一开始系统还能正常总结训练内容
- 到后面开始把 `Producer` 的说话习惯也一起总结
- 最终输出变成对 `Producer` 的人格侧写
- `広` 安静地读完，还觉得评价相当准确

### 笑点

- 工具没有先替人工作，反而先学会评价人
- `広` 对被冒犯毫无反应，对准确性却很满意
- `Producer` 想关掉程序，`広` 要求先保存结果

### 收尾

`広` 说：

“它已经开始观察负责人了。嗯。方向没错，只是有点失礼。”

### 用途

- 从 LLM 自然过渡到 agent
- 强化“AI 不只是会说，还会开始代做事”的感觉

## 售货机旁的五分钟补课

### 场景

自动售货机旁。`広` 站得不太稳，`Producer` 一边选饮料，一边被迫听课。

### 起因

`Producer` 只是问了一句“参数变大到底带来了什么”，结果 `広` 当场开始五分钟站立授课。

### 核心展开

- `広` 用售货机的按钮、库存和投币逻辑比喻模型选择
- 她讲到一半差点没力气，仍然不肯中断结构
- `Producer` 只想先把热饮递过去，`広` 却先把结论说完
- 周围路过同学会误以为他们在讨论某种极怪的消费哲学

### 笑点

- 场景极日常，内容却非常不日常
- `広` 能把任何东西都拿来比喻模型
- `Producer` 逐渐习惯“喝饮料前先上课”

### 收尾

饮料掉下来后，`広` 看了很久，说：

“嗯。输入明确，反馈清楚，动作单一。售货机也很适合当老师。”

### 用途

- 给 `ch02` 添加轻巧感
- 提前把售货机变成 recurring location

## `ch03` 到 `ch04` 之间

## agent 会做表格，但不会开门

### 场景

排练结束后，两人抱着一堆资料和杂物站在门口。

### 起因

前一晚刚测试过 agent 自动整理任务，结果今天现实里最需要它的时候，它什么都做不了。

### 核心展开

- agent 在平板里给出极其合理的搬运路线
- 但门还是得靠人开，东西还是得靠人拿
- `広` 状态不太好，站在门口看了很久
- 她不是抱怨系统不够聪明，而是直接指出：它没有身体，所以它其实没有接手任何事

### 笑点

- 系统的计划无懈可击，现实却卡死在门把手
- `Producer` 明明已经很累，还得被迫承认“具身智能确实不是噱头”
- `広` 像在给失败打分，而不是在抱怨

### 收尾

`広` 轻声说：

“它会安排。可是，门还是没有开。……这样不行。”

### 用途

- 直接把 `ch03` 推进到 `ch04`
- 给具身智能章节一个非常自然的切入口

## 如果请假条也是 agent 写的

### 场景

保健室外或活动室内。`広` 状态不好，`Producer` 忙着处理各种杂事。

### 起因

为了证明 agent 能分担工作，`Producer` 半开玩笑说不如让它先帮忙写请假说明。

### 核心展开

- agent 起草了一份过于冷静、过于精确的身体状态说明
- 内容准确得像医学记录，不像学生请假
- `Producer` 看完觉得不能真的交上去
- `広` 却觉得“写得很诚实”

### 笑点

- 请假条比本人还了解本人的极限
- `広` 对“被系统客观描述得很脆弱”这件事并不羞耻
- `Producer` 要在诚实和社会性之间艰难取舍

### 收尾

`広` 看着那张请假条，说：

“它已经很会描述停下来的样子了。下一步，是学会继续。”

### 用途

- 延续 `agent` 阶段的日常笑点
- 为 `ch04` 的“身体与继续”加情感预热

## `ch04` 到 `ch05` 之间

## 保健室复盘会议

### 场景

保健室。白窗帘、药味、很安静的下午光。

### 起因

`広` 因训练或搬运过程中过度消耗，被暂时安置在保健室。

### 核心展开

- `Producer` 原本想让她先休息，不要说话
- `広` 醒来后第一句却不是问自己怎样，而是问“刚才偏了多少”
- `Producer` 一边无奈，一边真的开始陪她复盘
- 复盘到后半段，两人已经像在开正式技术会议

### 笑点

- 保健室被他们硬生生开成项目复盘室
- `広` 对自己的失败有一种过度温柔的研究兴趣
- `Producer` 嘴上反对，实际上笔记记得比谁都认真

### 收尾

`広` 小声说：

“如果这里会停下来，就把这里记成节点吧。下次从这里接。”

### 用途

- 给 `ch04` 和 `ch05` 之间加一段安静但很重要的桥
- 让“小広计划”的情感核心更明显

## 地板上的失败标记

### 场景

练习室。地板上被贴了几段颜色不一样的胶带。

### 起因

`Producer` 发现 `広` 偷偷把自己最容易失误的位置做了标记。

### 核心展开

- `Producer` 以为她是在逃避那些位置
- 结果 `広` 反而把它们称为“最有价值的区域”
- 她想把失败高发点记下来，留给未来的控制系统和试作机一起学
- 最后甚至开始规划“失败地图”

### 笑点

- 别人用胶带标动作位置，`広` 用来标失败热点
- 她说话像在做学术数据可视化
- `Producer` 很想吐槽，却会被她的逻辑说服一半

### 收尾

`広` 说：

“顺利通过的地方，不太需要我。总是失败的地方，比较亲切。”

### 用途

- 给 `ch05` 的世界模型、预测和数据学习做意象铺垫
- 也很适合后续插图或小漫画

## `ch05` 到 `ch06` 之间

## 小広试作机第一次送水

### 场景

活动室或排练室门口。试作机第一次执行一个极其简单、却极其重要的任务。

### 起因

`広` 状态不好，`Producer` 忙着整理东西。两人决定测试“把水送过来”这种最基础的具身任务。

### 核心展开

- 试作机路线规划得很慢
- 中途差点撞椅子，绕了毫无必要的一大圈
- 杯子里的水甚至晃掉一点
- 但它最后真的停在 `広` 面前，把任务接上了

### 笑点

- 任务简单得不能再简单，完成过程却像史诗挑战
- `Producer` 紧张得像在看火箭着陆
- `広` 看它的眼神，比看很多优秀系统都更认真

### 收尾

`広` 接过水，说：

“很慢。很笨。也不稳定。……但是，已经不是零了。”

### 用途

- 非常适合做 `ch06` 前的情感预热
- 可以直接升级成后日谈的核心回收片段

---

## 试作机和植物管理权之争

### 场景

中庭或活动室窗边。`広` 的观叶植物成为试作机新的任务目标。

### 起因

为了让系统练习长期任务，`Producer` 想给它安排“定时照料植物”这种低风险工作。

### 核心展开

- 试作机开始把浇水当最高优先级
- `広` 观察后指出“太勤快会把植物弄坏”
- 于是她和 `Producer` 认真讨论“关心过头”是不是另一种控制失败
- 最后变成一堂很像 AI、安全边界和人与植物关系的奇怪小课

### 笑点

- 试作机第一次表现出的执着，居然是对植物
- `広` 会很护短地替植物说话
- `Producer` 会突然发现，这场争论本质上也在影射他平时怎么照顾 `広`

### 收尾

`広` 看着植物说：

“长得慢，不代表没有继续。浇太多，也是一种着急。”

### 用途

- 给主线一个柔软的侧面回声
- 适合放在 `ch06` 前，作为情感降落伞
