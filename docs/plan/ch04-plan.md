# ch04 改稿计划（历史稿）：门把手、胶带和零号机

> 状态说明：技术提纲仍可参考；关于“零号机”、跨章承接、小剧场和插画的安排已经停用。当前 `ch04` 采用可独立阅读的序章，以通用教学平台讲解视觉里程计、SLAM 与控制，不设置小剧场或漫画占位图。

## 本章新定位

`ch04` 从“具身智能综述”改成一次放学后的实践课：前一章的 agent 会安排任务、会写表格、会给路线建议，但在练习室门口无法开门、拿水、扶住杂物。于是 Producer 和広决定先做一个很小、很笨、但真的会碰到世界的“小広试作机零号”。

定稿设定：

- 机器人是“真实可做的低成本小车”方向：差速轮底盘、摄像头 / 简单深度传感器、IMU / 轮速计，外加一个非常简陋的两关节小机械臂或推杆。
- 写作时不需要过度抠成本和工程可复现性。同人作品可以允许一点奇怪过程，但技术骨架要让读者学到东西。
- 小机器人会随着章节逐步迭代。`ch04` 是零号机“刚能碰世界”，`ch05` 是用世界模型、VLA、sim2real 让它少犯同一种错，`ch06` 再回收一次很小的成功。
- 机械臂只讲两关节的平面小臂，避免深入复杂机械臂控制；SLAM、Navigation 和基础运动数学可以讲得更扎实。
- 章节标题改为：`具身智能 | 门把手、胶带和零号机`。

本章的知识重点放在“机器人如何感知到自己的运动，并把运动变成稳定动作”：

- 运动的数学：坐标系、位姿、速度、角速度、状态更新。
- 感知与状态估计：摄像头、IMU、轮速计、里程计、误差与漂移。
- SLAM 与导航：地图、定位、路线、避障、局部修正。
- 两关节小机械臂与“小脑”：关节角、平面逆运动学、PID / 简单顺应控制。

公式保留少量必要骨架，用来解释“为什么它会偏、为什么会撞、为什么需要闭环”，不做大段论文式铺陈。比喻优先使用初星学园现场：练习室地板胶带、舞台走位、服装间门口、搬道具、节拍和排练。

## 与总剧本的衔接

入口来自 `ch03` 后的短纲“agent 会做表格，但不会开门”：

- agent 给出合理搬运计划。
- 现实卡在门把手、地面、杂物和広的体力上。
- 広指出：不会碰世界的东西，不能叫“接手”。

出口指向 `ch05`：

- `ch04` 结尾留下一张“失败地图”和一批试作机日志。
- 这些日志说明：只会定位和控制还不够，试作机需要预测下一步、理解语言指令，并从仿真里多练几次。
- 于是 `ch05` 自然进入世界模型、VLA 与 sim2real。

## 小剧场安排

### 开场：门没有开

地点：初星学园，排练结束后的活动准备室门口。

剧情：

- Producer 抱着资料和水瓶，平板里的 agent 正在给出搬运路线。
- 路线很合理，但门还是要人开，道具还是会滑，広站了一会儿后体力明显下降。
- 広没有抱怨 agent，而是安静地指出：它只会安排，没有身体。

可用对白方向：

```text
広：它把路线排得很好。
P：然后我们卡在门口了。
広：嗯。门把手比它更接近现实。
```

### 中段：地板上的失败标记

地点：练习室。

剧情：

- 広把胶带贴在自己容易失误的位置，也贴在试作机容易偏航的位置。
- Producer 原本以为她在标“危险区域”，広纠正为“有价值的区域”。
- 由此引出状态估计、误差累积、回环校正。

### 收尾：零号机第一次移动

地点：练习室到活动室的小段路线。

剧情：

- 试作机零号是一台差速小车，加一个两关节小机械臂或推杆。
- 任务不是“像人一样行动”，而是沿着胶带走到桌边，把水瓶推近一点。
- 它偏航、犹豫、差点撞椅子，但能在 Producer 急停保护下完成一小段。

收尾句方向：

```text
広：很慢。
広：但是它刚才，把世界往前推了一点。
```

## 正文结构建议

### 1. 从“会说”到“会碰”

用小剧场后的余波进入正文，不先定义具身智能。

写法顺序：

1. 先写一个具体失败：agent 指挥搬运成功，现实执行失败。
2. 再总结具身智能的核心：智能必须进入“感知-状态-动作-反馈”的闭环。
3. 用偶像排练对应机器人闭环：看镜子 / 听节拍 / 调整步伐 / 回到站位。

需要避免：

- “具身智能是近年来热门方向”这类空泛开头。
- 一上来按论文史从 Brooks 讲起。历史可以压到旁注或短段。

### 2. 试作机零号的任务书

把本章技术内容全部挂到一个小项目上。

建议设定：

- 机体：差速轮小车 + 摄像头 / 简单深度传感器 + IMU / 轮速计 + 两关节小机械臂或推杆。
- 场地：练习室、活动准备室、服装间门口的短路线。
- 任务：从起点移动到桌边，避开椅子，推近水瓶或轻道具。
- 安全边界：不接近人脚，不搬重物，不在広体力不足时继续测试。

这份任务书可以写得像 Producer 的项目边界，也能保留広的奇怪兴奋感。

### 3. 运动的最小数学

目标：让读者真正知道机器人怎样“知道自己动了”。

保留少量公式：

```tex
x_t = x_{t-1} + v_t \cos \theta_t \Delta t
y_t = y_{t-1} + v_t \sin \theta_t \Delta t
\theta_t = \theta_{t-1} + \omega_t \Delta t
```

讲解方向：

- `x, y, theta` 对应机器人在练习室地板上的位置和朝向。
- `v` 和 `omega` 对应前进速度与转向速度。
- 轮子打滑、地板反光、转弯过急都会让预测位置偏掉。
- 这不是“机器人笨”，而是现实世界给状态更新加了噪声。

角色衔接：

```text
P：公式里它是直线走过去的。
広：现实里，地板没有那么听话。
```

### 4. SLAM 与导航：练习室里的迷你地图

目标：把 SLAM / Navigation 讲成试作机必须解决的流程。

建议小节内容：

- 传感器融合：摄像头看语义，轮速计估移动，IMU 感受转动。
- SLAM：一边估计自己在哪里，一边更新练习室地图。
- 导航：全局路径负责“从门口到桌边”，局部规划负责“别撞椅子和人”。
- 失败案例：椅子被人挪了，地图没更新；灯光反射导致视觉误判；轮子在地板上轻微打滑。

### 5. 两关节机械臂与“小脑”

目标：讲清“知道要拿水”和“真的碰到水瓶”之间的差距。

建议内容：

- 本章只讲平面两关节小臂：底座上一个肩关节、末端前一个肘关节。
- 正运动学回答“两个角度会把夹爪送到哪里”。
- 逆运动学只讲直觉：目标点太远够不到，目标点在可达圆环内才有解。
- PID / 简单顺应控制回答“动作怎么别冲过头、碰到东西怎么柔一点”。
- “小脑”比喻只用于控制层：不负责想任务，但负责让动作稳定、及时、不过猛。

公式只保留一到两个：

```tex
e_t = x_{\mathrm{target}} - x_t
u_t = K_p e_t + K_i \sum e_t + K_d(e_t-e_{t-1})
```

以及两关节小臂的正运动学，用来帮助读者看到“角度”和“末端位置”的关系。

### 6. 三次测试日志

把正文从讲义改成“试错记录”。

建议三轮：

1. **第一次：能走，但找不到自己。**  
   里程计累积误差，试作机偏到胶带外。
2. **第二次：能看，但不懂临时变化。**  
   椅子被挪动，局部避障来不及修。
3. **第三次：能碰，但角度和力气不合适。**  
   两关节小臂把末端送到了水瓶旁边，但角度偏了几度，推得太重，Producer 急停。

每轮结构：

- 现实现象。
- 技术拆解。
- Producer 设边界。
- 広给出短句式结论。

这样可以削弱“因为 A 所以 B”的说教感，让技术从现场自然出现。

### 7. 结尾：失败地图

结尾不追求成功，而是留下进入 `ch05` 的问题。

建议落点：

- 试作机零号完成了极小任务，但无法稳定泛化。
- 広把失败点贴成“失败地图”。
- Producer 发现这些失败不是废品，而是下一章需要的训练数据。
- 広提出：如果能先在一个小小的世界里预演，再让它听懂指令，也许下次会少撞一点。

可用结尾方向：

```text
広：这里会偏航。这里会犹豫。这里会撞。
P：听起来像缺点清单。
広：嗯。也是下一章的目录。
```

## 对白节奏原则

広：

- 先观察事实，再给出稍微异常但自洽的结论。
- 短句多，停顿多，不负责长篇解释。
- 她可以高兴于失败，但不能像在自毁；重点是“失败有观察价值”。

Producer：

- 不只是吐槽，要负责给试作机和広都加边界。
- 问题尽量操作化：它现在在哪、为什么偏、还能不能继续、危险在哪里。
- 该严厉时严厉，但严厉来自理解。

避免：

- `P：为什么？` / `広：因为……所以……` 的连续问答。
- 连续三段以上纯定义。
- 把広写成论文旁白机器。

- 标题改为 `具身智能 | 门把手、胶带和零号机`。
