# 中文自然技术写作

## 目标

让文本像一位具体作者在推理一个具体问题。自然感来自事实克制、因果结构、明确判断和有变化的节奏，不来自虚构轶事、装饰性口语或禁词表。

## 选择任务模式

选择能满足要求、改动最小的模式：

1. **只审校**：诊断问题并排列修复优先级，不改写原文。
2. **行级改写**：改善措辞和节奏，不改变主张或结构。
3. **结构重写**：重组段落顺序和论证流程，同时守住事实账本。
4. **基于来源起草**：只依据用户提供或已经核实的来源撰写新内容。

如果任务是准确翻译，保留能够取得的完整正文、原始顺序、代码、公式、图片和引用。不要悄悄把翻译变成改写。

## 工作流程

### 1. 明确写作约定

确定读者、体裁、目标长度、允许改写的程度、来源要求和交付格式。可以从上下文推断风险较低的细节；只有缺失的选择会实质改变结果时才询问用户。

编辑前先读本地指令和风格指南。除非用户明确要求新的声音，否则保留其现有写法。

### 2. 冻结事实账本

起草或结构重写前，分开记录：

- 用户提供或已经核实的事实；
- 需要注明归属的来源主张；
- 作者已经表达的解释；
- 你自己的推断；
- 未知或存在争议的部分。

不要为了让文字鲜活而编造数字、引用、引语、实验、日期、机构、个人经历或场景事件。不要把可能写成事实，也不要把相关性写成因果。缺少证据时，应诚实地概括、标记缺口或向用户索取来源。

### 3. 建立最小有效推理链

任务不只是行级改写时，可以优先采用下面的链路：

`现实问题 → 现有方案 → 已观察到的限制 → 提出的改变 → 作用机制 → 证据或例子 → 边界或代价 → 下一个问题`

这是一种诊断模型，不是强制使用的八段式模板。材料无法支持的环节应当省略。短小修改不需要另写大纲，也不需要额外等待用户确认。

按问题、机制、方法类别或争议组织研究材料，不要把论文逐篇排列。每个段落都应承担可以说清楚的论证职责。

### 4. 从三个层级诊断

按以下顺序检查：

1. **文章层级**：全文是否真的提出问题并逐步推进，还是只有宽泛开场和主题清单？
2. **段落层级**：每段是否推动了推理，还是重复强调重要性、空泛总结或机械预告下一节？
3. **句子层级**：是否存在翻译腔、空洞强调、模糊归因、强制三段式、同义词轮换、过量破折号或粗体，以及完全一致的节奏？

把具体措辞当作需要结合语境检查的信号，绝不能当作 AI 作者身份的证据。如果某个表达确实承担必要逻辑，就保留它。

### 5. 在尽量不扰动事实的前提下改写

- 从具体问题、观察、决定或矛盾开始。
- 用因果关系代替泛泛的过渡语。
- 把抽象赞美换成机制、后果或证据；无法替换时删除。
- 稳定使用已经确定的技术术语，不要为了变化而轮换近义词。
- 根据信息密度调整句子和段落长短。
- 让语气强度与证据强度一致；证据充分时直接表达判断。
- 只有作者确实拥有相应观察、决定或经历时才使用第一人称。
- 枚举有助于扫描时保留列表；论证依赖项目间关系时改写成连续文字。
- 除非任务明确要求修改，否则保留 LaTeX 命令、引用、标签、代码块、公式、网址和图片引用。

不要为了模拟人类作者而加入填充语、随意语气词、假装不完美的错误、无依据的情绪旁白或虚构履历。

### 6. 把技术材料解释两遍

公式、系统或方法是正文核心时：

1. 准确定义符号、输入、操作和输出；
2. 用自然语言重新说明完整机制；
3. 给出有来源支持的例子或边界；
4. 把解释重新连接到当前问题。

说明方法时覆盖 `输入 → 处理 → 输出 → 设计理由`。没有交代比较条件和证据时，不要声称某种方法更好。

### 7. 分两轮复核

**第一轮：事实与技术完整性**

- 主张与来源及其适用范围一致；
- 来源原文和作者推断有清楚区别；
- 术语、公式、单位、代码、引用和 LaTeX 保持完整；
- 例子没有超出证据。

**第二轮：自然程度与作者声音**

- 开头尽快抵达真正问题；
- 段落逐步累积，而不是反复重新开始；
- 结尾回答问题，而不是赞美主题；
- 节奏有变化，但不刻意表演；
- 用户要求的作者或角色声音体现在判断和选择中。

可以运行：

```bash
python3 scripts/audit_zh_writing.py 路径
```

把脚本输出当作复核线索。它只是启发式风格审校工具，不是 AI 检测器，也不提供作者身份评分。每一条命中都必须结合上下文判断。

如果本技能对 `hiroAiBook` 中的 `.tex` 源文件进行了有意义的修改，遵循仓库指令运行 `latexmk -xelatex main.tex`，并报告影响输出质量的警告。

## 交付结果

- 审校任务应返回按优先级排列的问题、对应位置和具体修复方向。
- 编辑任务应修改目标文件或提供改写结果，并概括实质性的结构或事实处理决定。
- 如实报告仍未解决的证据缺口，不要隐藏。
- 不要声称文本“由人类撰写”、保证绕过检测或完全没有 AI 痕迹。只描述能够观察到的写作改善。
