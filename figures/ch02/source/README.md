# Chapter 2 source images

These 21 files are the original-resolution illustrations embedded in
waterloo_intern's X article, *From GPT2 to Kimi3, Explained*:

<https://x.com/waterloo_intern/status/2081762065392541951>

They were downloaded from the article's `pbs.twimg.com` image URLs with
`name=orig`. The numbering follows the image order in the source article.

| Files | Subject |
| --- | --- |
| `original-01`--`original-05` | Attention timeline, GPT-2 architecture, embeddings, attention heads, and LM head |
| `original-06`--`original-07` | KV Cache data flow and growth |
| `original-08`--`original-12` | Linear attention, Delta Rule, chunkwise parallelism, and DeltaNet |
| `original-13`--`original-15` | Global decay and Gated DeltaNet |
| `original-16`--`original-18` | KDA evolution, code comparison, and Kimi Linear |
| `original-19`--`original-21` | Kimi K3, LatentMoE, and AttnRes |

The chapter uses a selected subset rather than reproducing every image.
